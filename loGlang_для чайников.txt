данная инфа об логленге
типы данных: 
r - регитры
# - метки в коде
& - адреса памяти
'const' - постоянные значения
P - номера портов

!!! всегда после указания вида операции нужно ставить точку для того чтобы эмулятор прочитал вашу комманду!

1. служебные вещи:
    halt- остановка программы 
    go - переход на определенную метку: go. #имя лейбла <- метка в коде
    label -  указание лейбла в коде: label. #yourlabel
    assig - присвоение регистру значения assig r3 '1'

2. арифметика:
    math - math. r1 + r2 r3
    mathr- mathr. "i" r1 '2' - i -> увеличение знач в регистре d -> противоположно i 
    3 ветвление:
    if - if r1 <>=$ r2 #твой лейбл
    #доллар - сравнение с числов, введённым в строке -> '4'

4. Работа с памятью.

    есть два указателя:
    
    для записи в память: ramw,
    
    для чтения из памяти в регистр: raml.
    
    также есть три флага для указания с чем будет работать: r, n, m 
    
    !!! флаги нужно заключать в двойные кавычки! "r"
    
    r - вводишь номер регистра и адрес, с которым работаешь: r4 &300 <- указание с какой ячейкой работать
    
    n (только с записью) - указываешь: 'твоё число' &адрес ячейки
    
    m - загрузка/запись в регистр по адресу из регистра: "m" r(куда положить из ячейки) r(откуда брать адрес ячейки)
    
    "c" - ввод массива в память с указанием начального адреса: ramw. "c" &нач. адрес [свои сисла через запятую] 

5. Ввод/вывод.
    
    Так как мне лень прописывать все порты, в папке эмулятора найдите файл "системные адреса" и берите оттуда нужные вам.
    
    в выводе также нужно прописать флаг, с чем будете работать.
    
    out. "r" - вывод значения из регистра.
    "n" вывод числа в порт (пригодится для различных функций связанных с эмулятором).
    
    input. "r"(только один флаг) P3 <- указание порта

пример простейшей программы, которая складывает два числа и выводит ответ в консоль:

    label. #main <- точка входа, но можно и без неё
        assig. r1 '4'
        assig. r2 '5'
        math. "r" r1 + r2 r3
        out. "r" r3 P5 <- системная комманда вывода значения в терминал python
    halt. <- точка останова, обязательно!

Для самых упорных постигателей знаний: 
    
    в моём языке можно писать кастомные модули, просто пишете свой код как обычно, но вместо halt пишете: global. "return"
    
    !!! модули закидывать в папку rmdc в эмуляторе!
    
    чтобы вызвать модуль: global. "имя модуля.txt"
    
    после работы программы она автоматически вернётся в начало.

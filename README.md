# loGsdk v1.0
КАК ПИСАТЬ ЗДЕСЬ КОД:

1. скачиваешь проект, распаковываешь архив. Также нужно будет скачать эмулятор по ссылке:https://github.com/alatock333-ai/logemu-main

2. открываешь файл execute.lbc.txt в любом удобном вам редакторе.

3. Пишете код, сохраняете файл.

4. Открываете файл logbscd.py, устанавливаете недостающие библиотеки через pip install (название библиотеки). !потребуется python не ниже 3.12 (можно и старше, но не проверено)

5. Появляется ассемблер уже в файле dopfile.txt, сам он не отчищается после каждой компиляции.

6. пишете свой код, описание языка находится в файле loGlang для чайников.

7. как запустить файл с кодом? переходите по ссылке в эмулятор и читайте readme там.

Удач!
